# Neon Last Call: Deluxe

Ein vollständiges, statisches Cyberpunk-Barkeeper-Spiel für den Browser. Es benötigt keinen Server, keine Bibliotheken und keinen Build-Schritt.

## Spielen

`index.html` doppelt anklicken oder den Ordner über einen kleinen lokalen Webserver öffnen.

## Auf GitHub Pages veröffentlichen

1. Neues GitHub-Repository anlegen.
2. `index.html`, `style.css`, `game.js` und `README.md` in die oberste Ebene hochladen.
3. In GitHub **Settings → Pages** öffnen.
4. Unter **Build and deployment** „Deploy from a branch“ auswählen.
5. Branch `main`, Ordner `/ (root)` auswählen und speichern.

Nach kurzer Zeit erscheint die öffentliche URL unter GitHub Pages.

## Spielumfang

- 10 unterschiedliche Gäste mit wiederkehrenden Dialogen
- Vertrauen, Chemie, Flirt und Romanzen
- 12 Cocktails, 20 Zutaten, drei Gläser und drei Eisarten
- Präzises Mixen in 5/10/15/25-ml-Schritten
- Zufallsereignisse und Story-Konsequenzen
- 8 Shopartikel und dauerhafte Upgrades
- Ruf, Tagesziele, Schichtberichte und Freischaltstufen
- Kontaktarchiv und 8 Erfolge
- Soundeffekte über die Web Audio API
- Automatisches Speichern per `localStorage`
- Responsive Bedienung für Desktop, Tablet und Smartphone

## Technische Hinweise

Der Spielstand verbleibt ausschließlich im Browser. Zum Zurücksetzen im Spiel „Neues Spiel“ verwenden oder den Website-Speicher löschen.
