# Neon Last Call – Flat Edition

Ein vollständig statisches Browser-Spiel für GitHub Pages. Alle Dateien liegen auf derselben Ebene; es gibt keine Unterordner und keinen Build-Schritt.

## Start

`index.html` im Browser öffnen.

## GitHub Pages

1. Alle Dateien in das Hauptverzeichnis eines GitHub-Repositories hochladen.
2. In **Settings → Pages** „Deploy from a branch“ wählen.
3. Branch `main` und Ordner `/root` auswählen.

## Enthalten

- Drei gezeichnete Cyberpunk-Gäste
- Dialog- und Flirtsystem
- Beziehungen: Vertrauen und Chemie
- Vier Cocktailrezepte und zwölf Zutaten
- Gedrückthalten zum Einschenken
- Sichtbarer Flüssigkeitsstand und dynamische Farbmischung
- Eiswürfel und Crushed Ice
- Shaken und Rühren
- Qualitätswertung, Trinkgeld, Ruf und Geld
- Shop-Upgrades
- Lokaler Spielstand
- Responsive Darstellung
