# Neon Last Call

**Version 2.3.0**

Ein vollständig statisches, animiertes Browser-Spiel für GitHub Pages. Alle Dateien liegen auf derselben Ebene; es gibt keine Unterordner und keinen Build-Schritt.

## Start

`index.html` im Browser öffnen.

## GitHub Pages

1. Alle Dateien in das Hauptverzeichnis eines GitHub-Repositories hochladen.
2. In **Settings → Pages** „Deploy from a branch“ wählen.
3. Branch `main` und Ordner `/root` auswählen.
