# Neon Last Call — Visual Edition

Ein statisches, grafisches Cyberpunk-Barkeeper-Spiel für GitHub Pages.

## Spielen
`index.html` lokal öffnen oder den Ordner auf GitHub Pages veröffentlichen.

## GitHub Pages
1. Alle Dateien in ein Repository hochladen.
2. Settings → Pages.
3. Deploy from a branch → `main` / `/root`.

## Features
- Animierte Canvas-Bar und sichtbare Gäste
- Eigene prozedural gezeichnete Figuren
- Dialoge, Vertrauen, Chemie und Flirtoptionen
- Flüssigkeit steigt beim Gedrückthalten einer Flasche sichtbar an
- Flüssigkeiten mischen ihre Farben dynamisch
- Eiswürfel und Crushed Ice werden im Glas angezeigt
- Shaker-Animation und Servieranimation
- Sechs Drinks und zwölf Zutaten
- Trinkgeld, Ruf, Nachtfortschritt, Shop und lokaler Spielstand
- Keine externen Bibliotheken oder Assets
