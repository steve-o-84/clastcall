# Neon Last Call: Premium

Statisches Browser-Spiel für GitHub Pages.

## Start
`index.html` lokal öffnen oder den gesamten Ordner in ein GitHub-Repository laden und GitHub Pages aktivieren.

## Hinweise
- Kein Build-Schritt
- Keine externen Bibliotheken
- Spielstand wird in `localStorage` gespeichert
- Die mitgelieferte Referenzgrafik stammt aus der vom Nutzer bereitgestellten Vorlage und wird als Hintergrund-/Porträtmaterial verwendet.
